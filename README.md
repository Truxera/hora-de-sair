# Hora de Sair
Aplicação web mobile desenvolvida para a disciplina de Introdução ao Desenvolvimento para Dispositivos Móveis.

## Problema
Dificuldade de cálculo de tempo de deslocamento para compromissos agendados, gerando atrasos frequentes.

## Objetivo
Auxiliar os usuários a se organizarem, calculando estimativas de saída com base na localização atual e horários marcados.

## Funcionalidades Previstas
- Captura de geolocalização via GPS do dispositivo.
- Gestão e persistência de compromissos utilizando `localStorage`.
- Cálculo simulado/estimado de tempo de percurso com base na distância.
- Monitoramento de rede Online/Offline.
